### 9. **Relations de Produits** 🔗

**4 types de relations :**

1. **Cross-Sell** (achats complémentaires)
   ```
   Laptop → Souris, Sac, Adaptateur
   ```

2. **Up-Sell** (version supérieure)
   ```
   Laptop i5 8GB → Laptop i7 16GB
   ```

3. **Alternatives** (produits similaires)
   ```
   MacBook Pro → Dell XPS, HP Spectre
   ```

4. **Accessoires** (compatibilité)
   ```
   iPhone 15 → Coque, Chargeur, AirPods
   ```

```
├── 10/01/2024: -5  (Ajustement: endommagé) → 40
└── 15/01/2024: +5  (Retour client) → 45
```

**Types de mouvements :**
- Ventes
- Retours
- Ajustements

## 🎨 Types de Produits Supportés

### 1. **Simple Product** 📱
Un seul produit, un prix, un stock
```
Exemple: Smartphone Samsung Galaxy S24
Prix: 899€
Stock: 150
```

### 2. **Variable Product** 👕
Produit avec variantes
```
Exemple: T-Shirt Premium
Variantes: Couleur x Taille
Total variantes: 18 (6 couleurs × 3 tailles)
```

### 3. **Bundle Product** 📦
Kit de plusieurs produits
```
Exemple: Kit Bureau Complet
5 produits inclus avec remise
```

### 4. **Configurable Product** ⚙️
Produit avec options personnalisables
```
Exemple: PC sur mesure
Options: CPU, RAM, GPU, Stockage
Prix final = Base + Options
```

## 🚀 Fonctionnalités Uniques vs Concurrents

### ✨ Ce que les concurrents N'ONT PAS :

1. **Catégories illimitées** (Alibaba: max 4 niveaux)
2. **Attributs 100% configurables** (Amazon: fixes)
3. **Bundles avec remises** (Faire: non disponible)
4. **4 types de relations produits** (Tous: max 1-2 types)
5. **Options configurables** (La plupart: non)
6. **Inventory log détaillé** (Tous: basique)
7. **Reviews avec images + vérification** (Basique partout)
8. **Collections flexibles** (Limité ailleurs)
9. **Prix tiers automatiques** (Manuel ailleurs)
10. **Support multi-types** (Simple/Variable/Bundle/Config)
